# Week 2 Molecular Dynamics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build, verify, optimize, document, and publish the Week 2 two-dimensional Lennard-Jones molecular-dynamics assignment.

**Architecture:** A Rust library owns simulation state and separates potentials, force searches, integrators, initialization, trajectory I/O, analysis, and rendering. A thin `md` binary exposes `run`, `check`, and `video`; examples and benchmark scripts consume the same public library functions as the CLI.

**Tech Stack:** Rust 1.98.1, Cargo, clap 4, serde/serde_json 1, rand/rand_chacha 0.9, rand_distr 0.5, plotters 0.3.7, ffmpeg, GNU Make, Python/NumPy baseline, samply profiler, GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-09-09-week2-md-design.md`

## Global Constraints

- Use reduced units with mass, Lennard-Jones epsilon, and sigma equal to one.
- Keep the plain potential and open boundaries available for the isolated dimer.
- Use velocity-Verlet, periodic minimum images, and shifted cutoff `r_c = 2.5` for production.
- Default run: `N=100`, `rho=0.8`, `T=0.5`, `dt=0.01`, 2,000 equilibration steps, 10,000 production steps, sample every 50, seed 2026.
- Generated default artifacts and Cargo build output remain ignored; published heating data under `docs/` are tracked intentionally.
- Every behavior change follows a witnessed RED test, minimal GREEN implementation, full regression run, and focused commit.
- Preserve all Week 1 files and existing repository history.

```rust
pub enum Boundary { Open, Periodic { box_size: [f64; 2] } }
pub enum PairModel { Plain, ShiftedCutoff { rc: f64 } }
pub struct System {
    pub pos: Vec<[f64; 2]>,
    pub vel: Vec<[f64; 2]>,
    pub force: Vec<[f64; 2]>,
    pub mass: f64,
    pub boundary: Boundary,
    pub pair_model: PairModel,
}
pub trait Integrator {
    fn name(&self) -> &'static str;
    fn step(&self, system: &mut System, dt: f64) -> f64;
}
pub struct EnergyTrace {
    pub relative_errors: Vec<f64>,
    pub max_relative_error: f64,
    pub final_relative_error: f64,
}
pub fn simulate_steps(
    mut system: System,
    integrator: &dyn Integrator,
    dt: f64,
    steps: usize,
) -> EnergyTrace;
```

Euler updates positions from old velocities and velocities from old forces.
Velocity-Verlet performs half kick, full drift, force refresh, half kick.
